# Retail Sales EDA

## 📊 Project Overview

This project analyzes retail sales data to uncover patterns in customer behavior, product performance, and sales trends. The goal is to provide actionable business insights.

## 🎯 Objectives

- Load and inspect the dataset
- Perform descriptive statistics
- Analyze time series trends (monthly & quarterly)
- Segment customers by age and gender
- Identify top product categories
- Visualize correlations between numeric features

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| Python | Core language |
| pandas | Data manipulation |
| matplotlib | Static visualizations |
| seaborn | Statistical visualizations |
| Jupyter Notebook | Interactive development |

## 📈 Key Findings

| Insight | Business Implication |
|---------|----------------------|
| Monthly sales peak in May (R50,000) | Seasonal promotions |
| Q4 is the strongest quarter (R130,000) | Holiday marketing focus |
| Clothing is the top category | Optimize inventory |
| Females lead in quantity sold | Targeted campaigns |
| Quantity strongly correlates with Total Amount (r = 0.85) | Volume drives revenue |

## 📋 About This Repository

This repository contains **data analytics projects** completed as part of the **Oasis Infobyte Internship Program**. Each project demonstrates hands-on application of data analytics skills — from exploratory data analysis to machine learning and fraud detection.

**Internship Period:** July – August 2026  
**Role:** Data Analytics Intern  
**Tech Stack:** Python, pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SQL

---

## 📁 Projects

| Task | Project | Description | Tools |
|------|---------|-------------|-------|
| **Task 1** | EDA on Retail Sales Data | Exploratory Data Analysis of 1,000 retail transactions. Uncovered sales trends, customer demographics, and product performance. | Python, pandas, matplotlib, seaborn |
| **Task 2** | House Price Prediction | Linear Regression model to predict house prices using features like area, bedrooms, location, and condition. Includes feature scaling, encoding, and model evaluation. | Python, pandas, scikit-learn, matplotlib, seaborn |
| **Task 3** | Fraud Detection | Classification models (Logistic Regression & Random Forest) to detect fraudulent credit card transactions. Addressed class imbalance using SMOTE. | Python, scikit-learn, imbalanced-learn, matplotlib, seaborn |
